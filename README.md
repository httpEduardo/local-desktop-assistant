# Local Desktop Assistant

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)

A lightweight desktop assistant built with Tkinter and a Transformers text-generation pipeline. It can keep a small knowledge base in a local JSON file between sessions.

## Run locally

Install the model dependency and launch the application:

```bash
pip install transformers
python "python assistente.py"
```

The first run may download the model selected by the script. Tkinter must also be available in your Python installation.
